## 本次完成的质量改进

- 明确实验项目、AI 辅助开发、支持系统、未签名程序和恢复系统行为。
- 补充安全与隐私说明、贡献指南、变更记录和脱敏问题模板。
- CI 使用只读权限、固定 checkout 提交和 Gitleaks 校验值；不自动上传测试日志或个人配置。
- 增加无交互桌面的逻辑测试，以及独立构建目录与测试超时。
- 自测配置与真实用户配置隔离；为窗口跟随测试增加 PID 范围，防止等待期间处理非测试窗口。

本机验证：Windows 三屏环境完整测试 **309 项通过**；无交互输入的逻辑测试 **124 项通过**。逻辑测试没有注入按键或创建窗口。远端 CI 结果需以对应工作流的实际状态为准；本记录不把本地通过写成远端已通过。

## 公开处理方案（2026-10-22）

维护者要求不保留旧仓库，直接整理为干净公开仓库。因此发布内容采用经过检查的当前源码，重新初始化 Git 历史，作者和提交者均使用 GitHub noreply 邮箱；同名 GitHub 仓库重新创建，不继承旧提交、标签、Release、PR 或 Actions 记录。

源码采用 MIT 许可证，许可证文本随公开源码和新版本发布包提供。所有公开发布均明确标注实验性，新的二进制使用新版本号与校验值。公开前再次验证新仓库的提交元数据、凭据扫描、构建和逻辑测试。

此前私有开发过程的审阅结论仅记录检查范围，不把旧历史上传至公开仓库。GitHub 自身的数据留存和已有第三方副本不由本项目控制；新仓库验证范围为可公开访问的提交、引用、元数据和附件。

## 公开后的定位

适合作为供学习、试用和反馈的**实验项目**；不应宣传为经过独立安全认证或生产级稳定的软件。窗口跟随采用启发式判断，第三方应用可拒绝操作；管理员窗口、全屏程序、长时间运行、显示器热插拔及不同 DPI 组合仍需要持续验证。EXE 目前没有数字签名，也没有自动更新与崩溃遥测。
