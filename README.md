# 选屏显示桌面 / ChoiceMinimizeWindow

> **实验性测试项目 / Experimental**：由 AI 辅助开发、个人维护，尚未经过独立安全审计或广泛兼容性验证。适合愿意反馈问题的 Windows 多屏用户，不承诺生产级稳定性。程序可能接管全局快捷键、改变焦点、最小化或移动窗口；首次使用请先在非关键工作环境测试。

Windows 11 多屏桌面小工具：按快捷键后选择屏幕，只最小化该屏上的窗口，再次选择同一屏还原。原生托盘常驻，单个 EXE，无第三方运行库、无网络访问、无需管理员权限。

## 下载与恢复系统行为

- 从本仓库的 [Releases](https://github.com/couger/choice__minimizewindow/releases) 获取 EXE 或 ZIP；ZIP 解压后运行 EXE。通过 Git 下载源码时不会自带编译好的程序，需要先构建。
- 支持目标：Windows 11 x64、系统自带 .NET Framework 4.x；其他系统、ARM64 原生运行及所有显示器/DPI 组合尚未充分验证。
- 发布程序目前**没有数字签名**，Windows 可能提示未知发布者。不要把本项目的说明当作绕过安全提示的依据；可以审查源码并自行构建。
- 要恢复 Windows 原生快捷键：托盘右键选择“暂停快捷键”、取消“启用”或退出。取消“启用”会保存；若不希望登录后运行，再关闭“随系统启动”。
- 登录自启动仅在用户开启后写入当前用户注册表。普通权限为默认方式；管理员模式需用户自行确认系统权限提示。

ChoiceMinimizeWindow is an experimental, AI-assisted Windows 11 x64 tray utility for per-monitor desktop toggling, application switching and foreground-window routing. Releases are unsigned. Read the limitations and recovery instructions before use.

## 使用

运行 `bin/ChoiceMinimizeWindow.exe`。默认快捷键：

| 功能 | 短按后松开 | 持续按住整个组合 2 秒 |
| --- | --- | --- |
| **Ctrl+Alt+D** | 显示／还原当前屏幕的桌面 | 选择要显示桌面的屏幕 |
| **Ctrl+Tab** | 切换当前屏幕中的应用窗口 | 选择屏幕，再选择该屏的应用窗口 |

长按时间可在托盘“设置与使用说明”中调整为 **0.5–5 秒**，默认 **2 秒**。短按只在松键时执行；长按只打开选择界面，不会先执行短按。键盘自动重复不会重复触发。持续按住修饰键、反复点按 Tab 可连续遍历同屏窗口，加 Shift 可反向切换。

选屏界面点击屏幕或按 **1–9**（兼容小键盘），**Esc** 取消。应用列表支持上下键、Enter 确认及鼠标双击。数字按屏幕从左到右、再从上到下排列，不一定与 Windows 显示设置中的编号一致。托盘也提供两个功能的直接选屏入口。

选屏和应用选择窗口显示时置顶，并在打开时获取键盘焦点；遇到激活时序竞争会短暂重试，成功后停止，不持续抢占焦点。应用列表每 400 毫秒刷新，窗口移屏后从原屏列表消失并出现在新屏列表中。显示桌面、当前焦点屏幕和应用切换使用同一套实时屏幕归属判断；最小化窗口按 Windows 保存的还原屏幕归属。

连续短按显示桌面快捷键时，目标保持为首次按下时的屏幕，避免最小化引起系统自动转移焦点后跳屏。鼠标点击或滚轮操作所在屏幕会成为当前屏幕，包括桌面空白、桌面图标、开始菜单、任务栏及应用窗口；即使前台窗口仍在另一屏，也按实际点击位置选屏。显示桌面和切换应用共同使用这个当前屏幕。在应用中使用其他普通按键后，改为按当前键盘焦点选屏；系统自动转移焦点不会导致连续显示桌面跳屏。长按后明确选择某屏也会更新目标。仅移动鼠标不会换屏。

**Ctrl+Tab 会接管浏览器等应用的标签页切换**。设置中可将切换应用改为 Alt+Tab、Ctrl+Alt+Tab，或单独停用此功能。关闭“启用”或暂停快捷键后恢复系统／应用原有快捷键。

如需沿用系统快捷键，可在设置中选用 **Win+D** 与 **Alt+Tab**。程序在被接管组合结束时阻止误弹开始菜单／菜单栏，单独按 Win 或 Alt 仍保留原有作用；不修改 Windows 的键盘映射。托盘“暂停快捷键”、取消“启用”或退出均可恢复系统原有行为。

### 远程桌面布局保护（实验性）

默认开启，托盘右键的“远程桌面布局保护”子菜单提供自动恢复开关、“保存当前布局”、“恢复手动保存的布局”和“恢复最近自动布局”。菜单显示手动记录的保存时间和窗口数量，不弹气泡。

**手动记录与自动记录独立保存**。点击“保存当前布局”后，手动记录只在下次明确点击保存时更新；之后移动窗口、等待后台自动记录、重启程序，都不会覆盖它。需要检验时可先保存，打乱窗口，等待任意时间后选择“恢复手动保存的布局”。远程连接前的自动记录继续滚动更新，回到本机时只使用自动记录，不会把更早的手动布局误用于自动恢复。关闭自动恢复后仍可手动保存与恢复。

手动记录使用同一配置目录中的 `layout-manual-a.dat`、`layout-manual-b.dat`，同样交替保留两代，发生写入中断时使用上一份完整记录。旧版只有滚动自动记录，升级不会把它误标为手动记录；请先手动保存一次。

本机屏幕布局稳定 5 秒后开始记录，自动保存有约 4 秒延迟。远程连接、锁屏或显示布局变化时冻结记录，并暂停窗口跟随；回到本机且原屏幕的分辨率、排列、主屏及任务栏工作区恢复并稳定 5 秒后，向仍存在的窗口发送还原请求，包括原位置、大小、最大化／最小化状态。仅断开远程连接但没有回到本机时不会提前恢复。

首次使用请先在本机摆好窗口，等待约 10 秒或手动“保存当前布局”，再连接远程桌面。更换显示器、调整分辨率或任务栏后，如需将新布局作为基准，请在本机稳定后手动保存。自动恢复开关独立保存；整体取消“启用”也会停止自动保存和恢复，“暂停快捷键”只暂停快捷键与窗口跟随。

记录保存在本机 `%LOCALAPPDATA%/ChoiceMinimizeWindow/` 内的 `layout-a.dat`、`layout-b.dat`，交替保存两代，写入中断时保留上一份完整记录；兼容读取旧的 `layout.dat`。包含屏幕几何信息、窗口句柄、进程编号、进程启动时间、窗口身份标记及位置状态，不包含窗口标题、程序路径或输入正文，不联网。窗口身份会同时核对，已经关闭或重新启动的程序不按旧记录搬动；远程期间新开的窗口没有原位置记录。注销远程会话会关闭程序，无法还原这些已关闭的窗口。管理员窗口需要相应权限，第三方软件仍可能拒绝或覆盖还原请求。

当前验证包括模拟会话／屏幕变化的逻辑测试，以及真实三屏上的专用测试窗口位置与状态恢复；**尚未完成真实 RDP 连接、断开、回到本机的端到端验证**。相同屏幕几何信息按同一布局处理，不能识别两台相同规格显示器互换物理接口的情况。

### 新开／唤出窗口跟随当前屏幕

默认开启，可从托盘右键或设置中单独关闭。点击桌面图标、任务栏图标、开始菜单、文件／快捷方式，或通过 Ctrl+E 等自定义全局快捷键唤出应用时，随后来到前台的普通窗口会优先移动到操作所在屏幕。也支持开始菜单搜索后回车、Win+E、Win+数字，以及 Ctrl+N、Ctrl+O 等打开新窗口的入口。此功能不注册或改写这些启动快捷键，只观察启动后出现的窗口。

已运行的应用从隐藏／最小化状态唤出或从另一屏来到前台时同样适用。普通窗口尽量保留相对位置与大小，超出目标屏工作区时缩小并限制在工作区内；最大化窗口移动后仍保持最大化，并更新还原位置。系统 Alt+Tab、关闭／最小化引起的焦点变化、后台窗口、工具浮窗和无边框全屏窗口不主动搬动。关闭“启用”或暂停快捷键时，也暂停窗口跟随。

这是基于近期操作与前台窗口变化的判断，无法精确识别所有第三方软件的启动意图。等待启动最长 10 秒；期间新的点击／键盘操作会更新或取消等待。启动特别慢、只在后台运行、没有新建或激活顶层窗口、仅打开标签页、或自行强制固定位置的程序可能不适用。管理员窗口仍要求本程序以管理员身份运行。

- 选屏界面按真实显示器布局排列，支持负坐标、竖屏和不同缩放比例。
- 屏幕操作只看窗口当前状态，不区分由本程序、手动还是其他软件最小化。有展开的普通窗口时，将它们全部最小化；该屏普通窗口都已最小化时，将它们全部还原，包括操作前就已最小化的窗口，并保留最大化状态。
- 按钮与托盘菜单按当前状态显示“显示桌面”或“还原窗口”；手动还原或最小化后，下次操作直接遵循实际状态。应用切换始终包含已最小化普通窗口，选择后还原并激活。“还原全部”处理所有屏幕的已最小化普通窗口。
- 跨屏窗口归属占用面积最大的一屏；整个窗口一起最小化。
- 双击托盘图标打开选屏；右键可按屏操作、还原全部、暂停快捷键、设置开机启动、退出。
- 托盘右键菜单的“启用”控制整个应用是否生效。取消勾选会释放快捷键与 Win+D 接管、还原已收起的窗口，并停用选屏操作；重新勾选后恢复。启用状态会保存，重启后保持。设置、自启动和退出仍可操作。
- 关闭界面收起到托盘；退出会先尝试还原本工具收起的所有窗口。
- 显示桌面快捷键可选 `Win+Alt+D`、`Ctrl+Alt+D`、`Win+Ctrl+D` 或接管 `Win+D`。快捷键监听只拦截配置的组合及其按键释放，不记录键入内容；暂停或退出即移除监听。

首次部署可运行 `ChoiceMinimizeWindow.exe --enable-startup`，启用当前用户登录自启动。正常使用也可在托盘或设置中切换。自启动以 `--tray` 参数运行，不弹主界面。移动 EXE 后请重新开启自启动。

重复运行 EXE 会打开已有实例，不会重复驻留。维护升级时可以使用 `ChoiceMinimizeWindow.exe --quit` 请求已有实例还原窗口并退出。

键盘监听和长按计时使用独立线程，避免界面绘制或窗口操作卡顿导致快捷键失效。监听每 30 秒在相关按键均已松开时重新注册，以恢复 Windows 静默移除的监听；暂停和停用期间不会恢复监听。

## 构建和验证

在 Windows PowerShell 中运行：

```powershell
.\build.ps1
.\test.ps1 -LogicOnly
# 以下完整测试会短暂创建窗口和托盘菜单，请在可操作的 Windows 桌面运行：
.\test.ps1
```

使用 Windows 自带 .NET Framework 4.x 的 64 位 C# 编译器。构建脚本为 EXE 设置 Medium 完整性标签，避免低完整性文件导致托盘注册受阻。自测只操作专门启动的测试进程窗口，不最小化用户窗口；验证多屏隔离、跨屏归属、最小化排除、最大化还原、全部还原和关闭窗口处理。

CI 自动执行构建与不依赖交互桌面的逻辑测试；完整 WinForms／多屏测试需要可操作的 Windows 桌面，不能用单屏 CI 结果代替真实多屏验证。测试使用独立配置目录，窗口跟随测试带有进程限制。测试输出位于 `test-results/`，不提交或默认上传。

配置及有大小上限的运行日志保存在 `%LOCALAPPDATA%/ChoiceMinimizeWindow/`。`interaction.txt` 保存长按毫秒数及切换应用快捷键；原有启用状态、桌面快捷键和自启动配置继续保留。自启动项位于当前用户 `Software/Microsoft/Windows/CurrentVersion/Run/ChoiceMinimizeWindow`。配置、日志和测试结果不提交仓库。

## 限制

以普通权限运行时，管理员窗口、独占全屏游戏或不支持最小化的窗口可能不响应。快捷键可能与其他软件的监听冲突，可在设置中更换组合。安全桌面、锁屏、其他虚拟桌面的隐藏窗口不处理。应用激活遵守 Windows 前台焦点限制。本工具只接管配置的两组快捷键。

需要操作管理员权限窗口时，可从托盘菜单选择“以管理员身份重启（支持管理员窗口）”，自行确认 Windows 权限提示。取消提示会保持原程序运行；确认后新实例接替旧实例。登录自启动仍使用普通权限。

“显示桌面”操作的还原记录仅在当前进程内保存；远程桌面布局保护另行保存本地布局文件，并核对仍存在的窗口身份。系统重启后原应用窗口不再存在，不能借此重新打开应用。窗口始终可从任务栏手动打开。热插拔显示器后会刷新选择布局，仍可通过“还原全部”处理先前屏幕的最小化记录。
